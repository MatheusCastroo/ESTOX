                    CONFIGURAÇÃO TÉCNICA
================================================================================

API URL (Detectada automaticamente):
  • Local:    http://localhost/ESTOCX/api
  • Produção: https://estocx.com.br/api (automático)

Endpoints Principais:
  • POST /api/auth?action=login          → Fazer login
  • GET  /api/auth                       → Validar token
  • GET  /api/admin/subscriptions        → Listar assinaturas
  • PUT  /api/admin/subscriptions        → Ações administrativas

================================================================================
                    SEGURANÇA
================================================================================

✅ Validações Implementadas:
   • Token JWT obrigatório
   • Role 'admin' obrigatória
   • Redirecionamento automático se não autorizado
   • Validação no frontend e backend

⚠️ Boas Práticas:
   • Altere a senha padrão após primeiro acesso
   • Delete criar-admin.php após configurar
   • Use HTTPS em produção (já configurado)
   • Faça logout após usar

================================================================================
                    SOLUÇÃO DE PROBLEMAS RÁPIDOS
================================================================================

❌ "Token não encontrado"
   → Faça login novamente em login.html

❌ "Acesso negado. Apenas administradores"
   → Execute no banco: UPDATE users SET role = 'admin' WHERE email = 'seu@email.com'
   → Faça login novamente

❌ Erro ao criar admin
   → Verifique se o arquivo .env existe em api/
   → Verifique as credenciais do banco no .env
